# ADR-001 … ADR-010 (initial set)

Status: Accepted for rebuild v0.1  
Date: 2026-08-04  
Repository: ClinicalPhysiologyLab

## ADR-001 — Patient Runtime as sole canonical-state authority

**Decision:** All changes to canonical patient state go through `PatientRuntime.dispatch` / `advance` / checkpoint restore.

**Consequence:** UI, scenarios, tests, and future agents share one API. Legacy `Patient.set` for `cordLevel` is bridged by the compatibility facade during migration.

## ADR-002 — Commands, queries, and observations as separate APIs

**Decision:** Mutating actions are commands; read models are queries; clinical information acquisition is `observe()`.

## ADR-003 — Public physiological ports versus private model parameters

**Decision:** Conditions emit effects on ports such as `vascular.systemicArteriolarTone`. Only model adapters may mention `Rsys`, `V0sv`, `Emax`, etc.

## ADR-004 — Deterministic effect composition with provenance

**Decision:** Each port declares a composition rule. Composition is order-independent unless priority is explicit. Every resolved value retains contribution provenance.

## ADR-005 — Ground truth, observation, and interpretation separation

**Decision:** Latent physiology, observation results, and interpretation labels are distinct types and code paths.

## ADR-006 — Command/event log plus checkpoints for replay

**Decision:** Reproducibility uses fingerprint + seed + accepted command log + periodic checkpoints — not every integrator step.

## ADR-007 — Scenario capability requirements and validation

**Decision:** Scenarios declare required capabilities; runtime initialisation fails clearly when the model set cannot satisfy them.

## ADR-008 — Initial model swap policy

**Decision:** Models are selected at runtime initialisation. Live mid-session swap is deferred.

## ADR-009 — Patient-first UI information architecture

**Decision:** Top-level experience layers are Patient / Examine / Investigate / Treat / Explore. Specialty workspaces remain as Explore lenses during migration.

## ADR-010 — Compatibility adapter strategy

**Decision:** Wrap the current circulation and ECG engines behind versioned adapters. Preserve validated private-parameter targets for complete C5 neurogenic shock (`Rsys` 0.52, `HR` 52, `V0sv` 2900, baroreflex off).
